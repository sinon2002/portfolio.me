# Portfolio

- `partials/header.html` — шапка (меню, заголовок, фото, иконки соцсетей)
- `partials/main.html` — «Обо мне» и «Мои работы»
- `partials/footer.html` — подвал (контакты)
- `css/style.css` — стили и цвета (переменные --bg, --ink, --red в начале)
- `images/photo.jpg` — твоё фото
- `index.html` — собирает всё вместе

Работает на Vercel / GitHub Pages. Локально открывай через сервер (например `npx serve`), не двойным кликом.
